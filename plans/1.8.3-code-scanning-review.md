## Scope and verification

The sync file format, salt/nonce lengths, authenticated header and cryptographic
algorithms are unchanged. A fixed encrypted fixture produced by the pre-fix code
must decrypt correctly and reproduce the same bytes with fixed synthetic inputs.
New tests cover isolation between passphrases, cache bounds, concurrent derivation,
reconfiguration/disable and probe cleanup. The browser test passes quotes,
script-like text and line separators through CDP unchanged, without executing them.

Reference cleanup is not a guarantee of physical erasure of immutable Python
objects, memory dumps or swap. An attacker with process-memory access may still
obtain active passphrases/keys. This change removes unnecessary retained material;
it does not claim protection against an already compromised host.

Only the narrowly identified synthetic-fixture alert warrants dismissal. No
query is disabled, no test directory is excluded, and fixes must be confirmed by
a fresh CodeQL analysis before being reported as resolved in GitHub. RC1 is an
immutable earlier build and does not contain this follow-up.
